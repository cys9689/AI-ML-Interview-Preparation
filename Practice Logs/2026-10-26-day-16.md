## Flood Fill Key Idea

Save the starting color before modifying the image. If the new color equals the original color, return immediately. Otherwise recolor cells when enqueuing them. Their changed color prevents repeat visits, so a separate visited set is unnecessary.

## Final Implementation

```python
from collections import deque

def floodFill(image, sr, sc, color):
    original_color = image[sr][sc]
    if original_color == color:
        return image
    image[sr][sc] = color
    queue = deque([(sr, sc)])
    while queue:
        row, col = queue.popleft()
        for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
            nr, nc = row + dr, col + dc
            if 0 <= nr < len(image) and 0 <= nc < len(image[0]):
                if image[nr][nc] == original_color:
                    image[nr][nc] = color
                    queue.append((nr, nc))
    return image
```

## Complexity

Worst-case time O(R * C). Auxiliary queue space has an O(R * C) upper bound. The image is modified in place; no visited set or image copy is allocated.

## Mistakes Caught

- Assignment uses =; == only compares.
- original_color is a variable, not the literal string "original_color".
- Check bounds before reading a neighboring pixel.
- Deque uses append(), not set's add().
