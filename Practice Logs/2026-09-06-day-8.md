## Pattern Distinction

Two pointers inward:

```text
left moves right
right moves left
loop often uses left < right
```

Sliding window:

```text
left moves right
right also moves right
right expands the window
left shrinks the window when invalid
```

## Problem 1: Best Time to Buy and Sell Stock

### Key Idea

Maintain:

```text
min_price_so_far
max_profit
```

For each price:

```text
profit = price - min_price_so_far
```

Then update max profit and minimum price.

### Final Code

```python
def maxProfit(prices):
    min_price_so_far = prices[0]
    max_profit = 0

    for price in prices:
        min_price_so_far = min(price, min_price_so_far)
        profit = price - min_price_so_far
        max_profit = max(profit, max_profit)

    return max_profit
```

### Complexity

```text
Time:  O(n)
Space: O(1)
```

## Problem 2: Longest Substring Without Repeating Characters

### Key Idea

Maintain a window with no duplicate characters.

If the current right character already exists in the window:

```text
move left rightward and remove characters from seen
until the duplicate disappears
```

### Final Code

```python
def lengthOfLongestSubstring(s):
    seen = set()
    left = 0
    max_len = 0

    for right in range(len(s)):
        while s[right] in seen:
            seen.remove(s[left])
            left += 1

        seen.add(s[right])
        max_len = max(max_len, right - left + 1)

    return max_len
```

### Complexity

Even though there is a nested `while`, time is still:

```text
O(n)
```

because:

```text
right moves right at most n times
left moves right at most n times
neither pointer moves backward
```

Space:

```text
O(min(n, charset_size))
```

## Problem 3: Longest Repeating Character Replacement

### Key Idea

For a window, keep the most frequent character and replace everything else.

```text
replace_needed = window_size - max_freq
```

Window is valid when:

```text
window_size - max_freq <= k
```

### Final Code

```python
def characterReplacement(s, k):
    count_map = {}
    left = 0
    max_len = 0

    for right in range(len(s)):
        if s[right] in count_map:
            count_map[s[right]] += 1
        else:
            count_map[s[right]] = 1

        while (right - left + 1) - max(count_map.values()) > k:
            count_map[s[left]] -= 1
            left += 1

        max_len = max(max_len, right - left + 1)

    return max_len
```

### Complexity

For uppercase English letters:

```text
Time:  O(n)
Space: O(1)
```

because `max(count_map.values())` scans at most 26 counts.

## Problem 4: Permutation in String

### Key Idea

This is a fixed-size sliding window.

If:

```text
m = len(s1)
```

then every candidate window in `s2` must have length `m`.

Check whether any length-`m` substring in `s2` has the same frequency map as `s1`.

### Final Code

```python
def checkInclusion(s1, s2):
    if len(s1) > len(s2):
        return False

    count_map = {}
    for ch in s1:
        count_map[ch] = count_map.get(ch, 0) + 1

    m = len(s1)

    window_map = {}
    for i in range(m):
        ch = s2[i]
        window_map[ch] = window_map.get(ch, 0) + 1

    left = 0
    right = m

    while right < len(s2):
        if count_map == window_map:
            return True

        left_ch = s2[left]
        window_map[left_ch] -= 1
        if window_map[left_ch] == 0:
            del window_map[left_ch]

        right_ch = s2[right]
        window_map[right_ch] = window_map.get(right_ch, 0) + 1

        left += 1
        right += 1

    return count_map == window_map
```

### Fixed Window Boundary

If:

```text
s1 = "ab"
m = 2
```

then:

```python
range(m)
```

produces:

```text
0, 1
```

so the first window has exactly two characters:

```text
s2[0], s2[1]
```

After the first window is built:

```text
right = m
```

points to the next character to add.

For example:

```text
s2 = "eidbaooo"
first window = "ei"
right = 2 -> s2[2] = "d"
```

Sliding from `"ei"` to `"id"` means:

```text
remove s2[0] = "e"
add s2[2] = "d"
```

The window remains length 2.

## Frequency Map Shortcut

Instead of:

```python
if ch in mp:
    mp[ch] += 1
else:
    mp[ch] = 1
```

use:

```python
mp[ch] = mp.get(ch, 0) + 1
```

When removing:

```python
mp[ch] -= 1
if mp[ch] == 0:
    del mp[ch]
```

## Mistakes Caught

- Substring must be continuous; subsequence does not need to be continuous.
- Sliding window pointers usually both move right.
- `right = m` means the next character to add after the first length-`m` window.
- `range(m)` excludes `m`.
- For Character Replacement, `k` is replacement count, not the number of distinct characters.
- For Permutation in String, window size is fixed at `len(s1)`.
