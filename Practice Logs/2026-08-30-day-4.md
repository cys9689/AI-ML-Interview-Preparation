# Day 4 Practice Log - K Closest Points to Origin

Date: 2026-08-30

## Topic

Heap / Top K by Distance

## Problem

K Closest Points to Origin

Given a list of points and an integer `k`, return the `k` points closest to the origin `(0, 0)`.

Each point is:

```text
[x, y]
```

Distance to origin:

```text
sqrt(x^2 + y^2)
```

For comparison, we can use squared distance:

```text
x^2 + y^2
```

because square root does not change the ordering for non-negative values.

## Example

```text
points = [[1, 3], [-2, 2], [2, -2]]
k = 2
```

Squared distances:

```text
[1, 3]   -> 10
[-2, 2]  -> 8
[2, -2]  -> 8
```

Closest two points:

```text
[[-2, 2], [2, -2]]
```

Order does not matter.

## Sorting Approach

Sort all points by squared distance and take the first `k`.

Complexity:

```text
Time:  O(n log n)
Space: O(n) in Python worst case
```

## Heap Approach

We need the `k` smallest distances.

Python `heapq` is a min heap. If we pushed positive distances and popped when size exceeded `k`, we would remove the closest point, which is the opposite of what we want.

So we use negative distance to simulate a max heap:

```text
(-distance, point)
```

The most distant point among the current candidates has the smallest negative distance and sits at `heap[0]`, so it can be popped when heap size exceeds `k`.

## Final Code

```python
import heapq

def kClosest(points, k):
    heap = []

    for point in points:
        distance = point[0] ** 2 + point[1] ** 2
        heapq.heappush(heap, (-distance, point))

        if len(heap) > k:
            heapq.heappop(heap)

    return [point for neg_dist, point in heap]
```

## Complexity

Let:

```text
n = len(points)
```

Distance calculation per point:

```text
O(1)
```

Heap max size:

```text
O(k)
```

Each heap push/pop:

```text
O(log k)
```

Overall time:

```text
O(n log k)
```

Space:

```text
O(k)
```

## Mistakes Caught

- `^ 2` is bitwise XOR in Python, not exponentiation.
- Use `x ** 2` or `x * x` for squared values.
- Push `(-distance, point)`, not just `-distance`, because the point is needed in the answer.
- Use `heapq.heappop(heap)`, not `heap.pop()`, because list pop does not preserve heap semantics.
- Heap space is `O(k)`, not `O(log k)`. `log k` is the operation time from heap height.

## Pattern Summary

Top K heap pattern:

```text
Keep a heap of size k.
Push each candidate.
If size > k, pop the least useful candidate.
Return what remains in the heap.
```

For K Closest Points:

```text
candidate priority = distance to origin
least useful candidate = farthest point among current k candidates
heap item = (-distance, point)
```
