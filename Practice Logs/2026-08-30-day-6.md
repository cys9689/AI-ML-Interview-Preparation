## Problem 1: Two Sum II

Given a sorted integer array `numbers` and an integer `target`, return the 1-indexed positions of two numbers whose sum equals `target`.

Example:

```text
numbers = [2, 7, 11, 15]
target = 9
output = [1, 2]
```

## Key Idea

Because the array is sorted:

```text
current_sum < target -> move left rightward to increase sum
current_sum > target -> move right leftward to decrease sum
```

Internally, Python uses 0-indexed positions:

```text
left = 0
right = len(numbers) - 1
```

But the answer must be 1-indexed:

```text
[left + 1, right + 1]
```

## Final Code

```python
def twoSum(numbers, target):
    left = 0
    right = len(numbers) - 1

    while left < right:
        current_sum = numbers[left] + numbers[right]

        if current_sum == target:
            return [left + 1, right + 1]

        if current_sum < target:
            left += 1
        else:
            right -= 1
```

## Complexity

Time:

```text
O(n)
```

Space:

```text
O(1)
```

## Problem 2: 3Sum

Given an integer array `nums`, return all unique triplets:

```text
[a, b, c]
```

such that:

```text
a + b + c == 0
```

Example:

```text
nums = [-1, 0, 1, 2, -1, -4]
output = [[-1, -1, 2], [-1, 0, 1]]
```

## Key Idea

Sort first, then fix one value with index `i`.

For each fixed `nums[i]`, solve a Two Sum II style problem on the right side:

```text
target = -nums[i]
left = i + 1
right = len(nums) - 1
```

If:

```text
nums[left] + nums[right] < target
```

move `left` rightward.

If:

```text
nums[left] + nums[right] > target
```

move `right` leftward.

If equal, record:

```text
[nums[i], nums[left], nums[right]]
```

## Final Code

```python
def threeSum(nums):
    nums = sorted(nums)
    result = []

    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue

        target = -nums[i]
        left = i + 1
        right = len(nums) - 1

        while left < right:
            current_sum = nums[left] + nums[right]

            if current_sum == target:
                result.append([nums[i], nums[left], nums[right]])
                left += 1
                right -= 1

                while left < right and nums[left] == nums[left - 1]:
                    left += 1

                while left < right and nums[right] == nums[right + 1]:
                    right -= 1

            elif current_sum < target:
                left += 1
            else:
                right -= 1

    return result
```

## Complexity

Sorting:

```text
O(n log n)
```

Outer loop plus two pointers:

```text
O(n^2)
```

Overall time:

```text
O(n^2)
```

Space:

```text
O(n) excluding output for this Python version, because `sorted(nums)` creates a new list.
```

If sorting in place and excluding output, the algorithmic extra space is commonly discussed as:

```text
O(1)
```

## Mistakes Caught

- For Two Sum II, code uses 0-indexed pointers but returns 1-indexed positions.
- In 3Sum, return value triplets, not indices.
- Duplicate `i` handling needs:

```python
if i > 0 and nums[i] == nums[i - 1]:
    continue
```

- Use `continue`, not `break`, when skipping duplicate fixed values.
- `right = len(nums) - 1`, not `len(nums - 1)`.
- Use `if / elif / else` so a found triplet does not accidentally move pointers twice.
- Skip duplicate `left` and `right` only after finding a valid triplet.
- Right pointer moves leftward, so duplicate skipping uses `right -= 1`.

## Pattern Summary

Two Sum II:

```text
sorted array + two pointers
sum too small -> left += 1
sum too large -> right -= 1
```

3Sum:

```text
sort
fix one number
run two pointers on the remaining suffix
skip duplicates carefully
```
