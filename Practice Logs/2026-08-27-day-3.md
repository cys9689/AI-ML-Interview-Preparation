# Day 3 Practice Log - Heap Patterns

## Topic

Heap / Size-k Min Heap

## Problems

1. Top K Frequent Elements - heap version
2. Kth Largest Element in an Array

## Core Heap Idea

Python `heapq` is a min heap:

```text
heap[0] is always the smallest element in the heap.
```

For tuple values, Python compares from the first item:

```text
(count, num)
```

This means the heap is primarily ordered by `count`.

## Problem 1: Top K Frequent Elements

### Key Idea

Use a frequency map first:

```text
num -> count
```

Then maintain a min heap of size `k`:

```text
(count, num)
```

Whenever heap size becomes greater than `k`, pop the smallest count.

### Final Code

```python
import heapq

def topKFrequent(nums, k):
    freq_map = {}
    for num in nums:
        if num in freq_map:
            freq_map[num] += 1
        else:
            freq_map[num] = 1

    min_heap = []
    for key, value in freq_map.items():
        heapq.heappush(min_heap, (value, key))
        if len(min_heap) > k:
            heapq.heappop(min_heap)

    return [num for count, num in min_heap]
```

### Complexity

Let:

```text
n = len(nums)
m = number of unique elements
k = number of results requested
```

Build frequency map:

```text
O(n)
```

Heap operations:

```text
m elements * O(log k)
```

Overall time:

```text
O(n + m log k)
```

Space:

```text
O(m + k)
```

Worst case:

```text
O(n)
```

## Problem 2: Kth Largest Element

### Key Idea

Maintain a min heap of size `k`.

The heap always keeps the current top `k` largest numbers.

```text
heap[0]
```

is the smallest among those top `k` numbers, so it is the kth largest number overall.

### Final Code

```python
import heapq

def findKthLargest(nums, k):
    heap = []

    for num in nums:
        heapq.heappush(heap, num)
        if len(heap) > k:
            heapq.heappop(heap)

    return heap[0]
```

### Complexity

Each heap operation costs:

```text
O(log k)
```

There are `n` numbers:

```text
O(n log k)
```

Space:

```text
O(k)
```

## Mistakes Caught

- `heapq` is a module, not a class. Use a normal list as the heap.
- Use `heapq.heappush(heap, item)`, not `heapq.push`.
- Use `heapq.heappop(heap)`, not `heapq.pop`.
- Heap only guarantees `heap[0]` is the minimum; the list is not fully sorted.
- In `(count, num)`, the first value is frequency/count, not the original number.
- For Kth Largest, duplicates count as separate positions.

## Pattern Summary

Size-k min heap:

```text
Push each candidate.
If heap size > k, pop the smallest.
At the end, heap contains the top k candidates.
```

For Kth Largest:

```text
return heap[0]
```

For Top K Frequent:

```text
return [num for count, num in heap]
```
