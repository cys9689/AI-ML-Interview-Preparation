## Problem 1: Min Stack

Design a stack that supports:

```text
push(val)
pop()
top()
getMin()
```

Each operation should be:

```text
O(1)
```

## Key Idea

A normal stack can support `push`, `pop`, and `top` in O(1), but it cannot get the minimum value in O(1) without extra information.

Use two stacks:

```text
main_stack: stores all values
min_stack: stores the minimum value at each stack depth
```

For example:

```text
push(5)
push(4)
push(6)
push(3)

main_stack = [5, 4, 6, 3]
min_stack  = [5, 4, 4, 3]
getMin()   = 3
```

If we pop `3`:

```text
main_stack = [5, 4, 6]
min_stack  = [5, 4, 4]
getMin()   = 4
```

Both stacks must pop together to keep stack depth aligned.

## Final Code

```python
class MinStack:

    def __init__(self):
        self.main_stack = []
        self.min_stack = []

    def push(self, val):
        self.main_stack.append(val)

        if not self.min_stack:
            self.min_stack.append(val)
        else:
            current_min = min(val, self.min_stack[-1])
            self.min_stack.append(current_min)

    def pop(self):
        self.main_stack.pop()
        self.min_stack.pop()

    def top(self):
        return self.main_stack[-1]

    def getMin(self):
        return self.min_stack[-1]
```

## Complexity

Each operation:

```text
O(1)
```

Space:

```text
O(n)
```

because `min_stack` stores one current-min value for every element in `main_stack`.

## Problem 2: Daily Temperatures

Given an array `temperatures`, return an array `answer` where:

```text
answer[i]
```

is the number of days until a warmer temperature. If none exists, keep `0`.

Example:

```text
temperatures = [73, 74, 75, 71]
answer       = [1, 1, 0, 0]
```

## Key Idea

Use a monotonic decreasing stack.

The stack stores indices of days that have not found a warmer future day yet.

When current temperature is warmer than the temperature at stack top:

```text
old_index = stack.pop()
answer[old_index] = current_index - old_index
```

Then push the current index because today also needs to wait for a warmer future day.

## Final Code

```python
def dailyTemperatures(temperatures):
    answer = [0] * len(temperatures)
    stack = []

    for i in range(len(temperatures)):
        while stack and temperatures[i] > temperatures[stack[-1]]:
            old_index = stack.pop()
            answer[old_index] = i - old_index

        stack.append(i)

    return answer
```

## Complexity

Time:

```text
O(n)
```

Even though there is a nested `while`, each index is:

```text
pushed once
popped at most once
```

So total stack operations are:

```text
O(n) pushes + O(n) pops = O(n)
```

This is amortized analysis.

Space:

```text
O(n)
```

Worst case:

```text
temperatures are monotonically decreasing
```

Example:

```text
[80, 79, 78, 77]
```

Then all indices stay in the stack.

## Mistakes Caught

- `min_stack` is not a sorted stack. It stores the current minimum at each depth.
- `min_stack` length should match `main_stack` length in this implementation.
- Daily Temperatures stack stores indices, not temperatures.
- Pop condition compares current temperature with `temperatures[stack[-1]]`, not with `temperatures[i - 1]`.
- Updating answer uses the popped index:

```python
answer[old_index] = i - old_index
```

- Nested `while` does not automatically mean O(n^2). In monotonic stack, every index can be popped only once.

## Pattern Summary

Min Stack:

```text
Use an auxiliary stack to preserve historical minimum state.
```

Daily Temperatures:

```text
Use a monotonic decreasing stack of unresolved indices.
When a warmer day arrives, resolve as many previous days as possible.
```
