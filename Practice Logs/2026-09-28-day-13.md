## Problem 1: Koko Eating Bananas

### Key Idea

This is binary search on the answer, not binary search over the input array.

Search range:

```text
left = 1
right = max(piles)
```

`mid` represents eating speed.

For a given speed, compute total hours:

```python
(pile + speed - 1) // speed
```

This is integer ceiling division.

If total hours are greater than `h`, speed is too slow:

```python
left = speed + 1
```

If total hours are less than or equal to `h`, speed is feasible, but may not be minimal:

```python
right = speed
```

### Final Code

```python
def minEatingSpeed(piles, h):
    left = 1
    right = max(piles)

    while left < right:
        speed = left + (right - left) // 2
        total_hour = 0

        for pile in piles:
            total_hour += (pile + speed - 1) // speed

        if total_hour > h:
            left = speed + 1
        else:
            right = speed

    return left
```

### Complexity

Let:

```text
n = len(piles)
M = max(piles)
```

Time:

```text
O(n log M)
```

Space:

```text
O(1)
```

## Problem 2: Reverse Linked List

### Key Idea

Reverse each node's `next` pointer.

Maintain:

```text
prev
curr
next_node
```

Order matters:

```python
next_node = curr.next
curr.next = prev
prev = curr
curr = next_node
```

`next_node` must be saved before rewriting `curr.next`, otherwise the rest of the list is lost.

### Final Code

```python
def reverseList(head):
    prev = None
    curr = head

    while curr:
        next_node = curr.next
        curr.next = prev
        prev = curr
        curr = next_node

    return prev
```

### Complexity

```text
Time:  O(n)
Space: O(1)
```

## Problem 3: Linked List Cycle

### Key Idea

Hash set version stores node references, not node values.

Two nodes may have the same `val` but still be different node objects.

Optimized version uses slow/fast pointers:

```text
slow moves 1 step
fast moves 2 steps
```

If there is no cycle:

```text
fast reaches None
```

If there is a cycle:

```text
fast eventually catches slow inside the cycle
```

Loop condition:

```python
while fast and fast.next:
```

Both checks are needed because `fast.next.next` is accessed.

### Final Code

```python
def hasCycle(head):
    slow, fast = head, head

    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next

        if slow == fast:
            return True

    return False
```

### Complexity

```text
Time:  O(n)
Space: O(1)
```

## Problem 4: Merge Two Sorted Lists

### Key Idea

Use:

```text
dummy node
tail pointer
```

Compare `list1.val` and `list2.val`, attach the smaller node, and advance that list pointer.

At the end, attach the remaining list directly because it is already sorted.

### Final Code

```python
def mergeTwoLists(list1, list2):
    dummy = ListNode()
    tail = dummy

    while list1 and list2:
        if list1.val <= list2.val:
            tail.next = list1
            list1 = list1.next
        else:
            tail.next = list2
            list2 = list2.next

        tail = tail.next

    if list1:
        tail.next = list1
    else:
        tail.next = list2

    return dummy.next
```

### Complexity

Let:

```text
m = len(list1)
n = len(list2)
```

Time:

```text
O(m + n)
```

Space:

```text
O(1)
```

This relinks existing nodes. It does not create a new copied linked list, apart from the dummy node.

## Problem 5: Maximum Depth of Binary Tree

### Key Idea

Define:

```text
maxDepth(root) = maximum depth of the tree rooted at root
```

Base case:

```python
if root is None:
    return 0
```

Recursive relation:

```text
1 + max(left_depth, right_depth)
```

### Final Code

```python
def maxDepth(root):
    if root is None:
        return 0

    left_depth = maxDepth(root.left)
    right_depth = maxDepth(root.right)

    return 1 + max(left_depth, right_depth)
```

### Complexity

```text
Time:  O(n)
Space: O(h)
```

where `h` is tree height.

Worst case skewed tree:

```text
O(n)
```

Balanced tree:

```text
O(log n)
```

## Problem 6: Invert Binary Tree

### Key Idea

Base case:

```python
if root is None:
    return None
```

For a real node:

```text
invert left subtree
invert right subtree
swap them
return root
```

Leaf nodes should return themselves, not `None`.

### Final Code

```python
def invertTree(root):
    if root is None:
        return None

    left = invertTree(root.left)
    right = invertTree(root.right)

    root.left = right
    root.right = left

    return root
```

### Complexity

```text
Time:  O(n)
Space: O(h)
```

## Problem 7: Same Tree

### Key Idea

Two trees are the same only if:

```text
structure is the same
values are the same
left subtrees are the same
right subtrees are the same
```

Base cases:

```text
both None -> True
one None -> False
different values -> False
```

Recursive relation:

```python
isSameTree(p.left, q.left) and isSameTree(p.right, q.right)
```

Use `and` because both sides must match.

### Final Code

```python
def isSameTree(p, q):
    if p is None and q is None:
        return True
    elif (p is None and q is not None) or (p is not None and q is None):
        return False
    elif p.val != q.val:
        return False
    else:
        return isSameTree(p.right, q.right) and isSameTree(p.left, q.left)
```

Simplified version:

```python
def isSameTree(p, q):
    if not p and not q:
        return True
    if not p or not q:
        return False
    if p.val != q.val:
        return False

    return isSameTree(p.left, q.left) and isSameTree(p.right, q.right)
```

### Complexity

```text
Time:  O(n)
Space: O(h)
```

## Recursion Template

For tree recursion, use this process:

```text
1. Define what the function returns.
2. Identify the empty-tree base case.
3. Ask the left subtree for its answer.
4. Ask the right subtree for its answer.
5. Combine those answers at the current node.
```

Do not start by mentally simulating the entire tree. Define the function contract and trust the recursive calls.

## Mistakes Caught

- Empty tree depth is `0`; single-node tree depth is `1`.
- A leaf node is not the base case for most clean tree recursion. `None` is.
- Tree recursion usually returns a node or computed value, not `node.val` unless the problem asks for values.
- In linked list code, `curr = head`, not `curr = head.val`.
- In cycle detection, store node references, not node values.
- `while fast and fast.next` prevents accessing `.next` on `None`.
- In merge lists, compare `list1.val <= list2.val`, not `list1.val <= list2`.
