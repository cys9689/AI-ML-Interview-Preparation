## Review: Minimum Window Substring

### Key Concepts

For:

```text
t = "AABC"
```

the need map is:

```text
{"A": 2, "B": 1, "C": 1}
```

`required` is the number of unique required characters:

```text
required = 3
```

not the total length of `t`.

`formed` counts how many required character types are currently satisfied.

### Formed Update Rules

When expanding right:

```python
if ch in need and window[ch] == need[ch]:
    formed += 1
```

Use equality because a character type should only increase `formed` when it changes from unsatisfied to satisfied.

When shrinking left:

```python
window[left_ch] -= 1

if left_ch in need and window[left_ch] < need[left_ch]:
    formed -= 1
```

Use `<` because a character type should only decrease `formed` when it changes from satisfied to unsatisfied.

### Return Slice

If:

```text
start = 9
min_len = 4
```

return:

```python
s[start:start + min_len]
```

because `min_len` is a length, not an end index.

## Binary Search: Classic Search

### Problem

Given a sorted array `nums` and a `target`, return the target index if found. Otherwise return `-1`.

### Key Idea

Use closed interval:

```text
[left, right]
```

Initialize:

```python
left = 0
right = len(nums) - 1
```

Loop while:

```python
left <= right
```

because when:

```text
left == right
```

there is still one candidate index left to check.

The search space is empty only when:

```text
left > right
```

### Final Code

```python
def search(nums, target):
    left, right = 0, len(nums) - 1

    while left <= right:
        mid = left + (right - left) // 2

        if nums[mid] < target:
            left = mid + 1
        elif nums[mid] > target:
            right = mid - 1
        else:
            return mid

    return -1
```

### Complexity

```text
Time:  O(log n)
Space: O(1)
```

## Binary Search: Search Insert Position

### Problem

Given a sorted array without duplicates and a target, return the index if found.
If not found, return the insertion position that preserves sorted order.

### Key Idea

When target is not found, return:

```python
left
```

After the loop:

```text
right points to the last value < target
left points to the first value >= target
```

So insertion position is:

```text
left
```

If target is larger than all elements:

```text
left == len(nums)
```

### Final Code

```python
def searchInsert(nums, target):
    left = 0
    right = len(nums) - 1

    while left <= right:
        mid = left + (right - left) // 2

        if nums[mid] == target:
            return mid
        elif nums[mid] > target:
            right = mid - 1
        else:
            left = mid + 1

    return left
```

### Complexity

```text
Time:  O(log n)
Space: O(1)
```

## Binary Search: Search in Rotated Sorted Array

### Problem

Given a rotated sorted array and a target, return the target index if found.
Otherwise return `-1`.

Example:

```text
nums = [4, 5, 6, 7, 0, 1, 2]
target = 0
output = 4
```

### Key Idea

At every step, at least one half is sorted.

First check:

```python
if nums[mid] == target:
    return mid
```

Then determine whether the left half is sorted:

```python
nums[left] <= nums[mid]
```

If left half is sorted, check whether target is inside:

```python
nums[left] <= target < nums[mid]
```

If right half is sorted, check whether target is inside:

```python
nums[mid] < target <= nums[right]
```

Do not use:

```python
target in nums[...]
```

because that is linear search and breaks the O(log n) goal.

### Final Code

```python
def search(nums, target):
    left = 0
    right = len(nums) - 1

    while left <= right:
        mid = left + (right - left) // 2

        if nums[mid] == target:
            return mid

        elif nums[left] <= nums[mid]:
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1

        else:
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1

    return -1
```

### Complexity

```text
Time:  O(log n)
Space: O(1)
```

## Mistakes Caught

- `left` and `right` are indices, not values.
- For closed interval binary search, use `while left <= right`.
- `left == right` means one candidate remains.
- `left > right` means the search space is empty.
- Search Insert Position returns `left`, not `-1`, when target is missing.
- If target is greater than all elements, insertion position is `len(nums)`.
- In rotated search, do not use slices or `in`; use boundary comparisons only.
