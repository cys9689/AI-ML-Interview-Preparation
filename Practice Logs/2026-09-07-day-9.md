# Day 9 Practice Log - Minimum Window Substring Intro

Date: 2026-09-07

## Topic

Sliding Window

## Problem

Minimum Window Substring

Given two strings `s` and `t`, return the minimum window substring of `s` such that every character in `t`, including duplicate counts, is included in the window.

If no such window exists, return:

```text
""
```

Example:

```text
s = "ADOBECODEBANC"
t = "ABC"
output = "BANC"
```

## Concepts Covered

Minimum Window Substring is similar to Permutation in String because both require:

```text
frequency map
checking whether a window satisfies character requirements
```

But the key difference is:

```text
Permutation in String:
fixed-size window
window_count must equal need exactly

Minimum Window Substring:
variable-size window
window_count only needs to satisfy need at least
extra characters are allowed
goal is the shortest valid window
```

## Valid Window Condition

For every character in `t`:

```text
window_count[ch] >= need[ch]
```

Example:

```text
t = "AABC"
need = {"A": 2, "B": 1, "C": 1}
```

This window is not valid:

```text
{"A": 1, "B": 1, "C": 1}
```

because it is missing one `A`.

This window is valid:

```text
{"A": 2, "B": 1, "C": 1, "D": 5}
```

because all required character counts are satisfied. Extra `D` values do not matter.

## Next Session Starting Point

Continue from the `formed` / `required` idea:

```text
required = number of unique characters in need
formed = number of required characters whose window count is currently satisfied
```

Window is valid when:

```text
formed == required
```
