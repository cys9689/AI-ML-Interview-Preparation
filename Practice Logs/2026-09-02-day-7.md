# Day 7 Practice Log - Trapping Rain Water

Date: 2026-09-02

## Topic

Two Pointers / Prefix-Suffix Max

## Problem

Trapping Rain Water

Given a non-negative integer array `height`, where each value represents a bar height, compute how much water can be trapped after raining.

Example:

```text
height = [0,1,0,2,1,0,1,3,2,1,2,1]
output = 6
```

## Core Formula

For any index `i`, the water above that bar depends on:

```text
left_max[i]
right_max[i]
height[i]
```

The water level is limited by the shorter boundary:

```text
min(left_max[i], right_max[i])
```

So:

```text
water_at_i = min(left_max[i], right_max[i]) - height[i]
```

Meaning:

```text
left_max[i]  = highest bar from the left up to index i
right_max[i] = highest bar from the right up to index i
height[i]    = current bar height
```

## Prefix/Suffix Version

### Key Idea

Precompute:

```text
left_max array
right_max array
```

Then calculate water at each index using:

```text
min(left_max[i], right_max[i]) - height[i]
```

### Final Code

```python
def trap(height):
    left_max, right_max = [0] * len(height), [0] * len(height)

    max_height = 0
    for i in range(len(height)):
        max_height = max(max_height, height[i])
        left_max[i] = max_height

    max_height = 0
    for i in range(len(height) - 1, -1, -1):
        max_height = max(max_height, height[i])
        right_max[i] = max_height

    total_water = 0
    for i in range(len(height)):
        water = min(left_max[i], right_max[i]) - height[i]
        total_water += water

    return total_water
```

### Complexity

Time:

```text
O(n)
```

Space:

```text
O(n)
```

because of `left_max` and `right_max`.

## O(1) Two Pointers Version

### Key Idea

Instead of storing full arrays, maintain only:

```text
left_max
right_max
```

Use:

```text
left = 0
right = len(height) - 1
```

Loop condition:

```text
while left < right
```

Processing condition:

```text
if height[left] < height[right]:
    process left
else:
    process right
```

Important distinction:

```text
left < right
```

is the loop condition.

```text
height[left] < height[right]
```

decides which side to process.

### Final Code

```python
def trap(height):
    left, right = 0, len(height) - 1
    total = 0
    left_max, right_max = 0, 0

    while left < right:
        if height[left] < height[right]:
            left_max = max(left_max, height[left])
            total += left_max - height[left]
            left += 1
        else:
            right_max = max(right_max, height[right])
            total += right_max - height[right]
            right -= 1

    return total
```

### Complexity

Time:

```text
O(n)
```

Space:

```text
O(1)
```

because it does not store the full `left_max` and `right_max` arrays.

## Mistakes Caught

- `max_height = (max_height, height[i])` creates a tuple. Use:

```python
max_height = max(max_height, height[i])
```

- `min(left_max[i], right_max[i])` uses function call syntax, not bracket syntax.
- `left_max` in the two-pointer version is a height value, not an index.
- Water amount is:

```text
boundary_height - current_bar_height
```

not just:

```text
boundary_height
```

- In the O(1) version:

```text
while left < right
```

and:

```text
height[left] < height[right]
```

serve different purposes.

## Pattern Summary

Prefix/suffix version:

```text
Store all left/right boundaries first.
Then compute each index independently.
```

Two pointers version:

```text
Process the shorter side.
Maintain only the best boundary seen so far on each side.
Accumulate water as boundary - current height.
```
