# Day 5 Practice Log - Valid Palindrome

Date: 2026-08-30

## Topic

Two Pointers

## Problem

Valid Palindrome

Given a string `s`, determine whether it is a palindrome after:

```text
1. keeping only alphanumeric characters
2. ignoring case
```

Example:

```text
s = "A man, a plan, a canal: Panama"
output = True
```

After filtering and lowercasing:

```text
"amanaplanacanalpanama"
```

This reads the same forward and backward.

## Key Idea

Use two pointers:

```text
left = 0
right = len(s) - 1
```

Move `left` from the start and `right` from the end.

Skip non-alphanumeric characters on both sides.

When both sides point to alphanumeric characters, compare them in lowercase.

## Final Code

```python
def isPalindrome(s):
    left = 0
    right = len(s) - 1

    while left < right:
        while left < right and not s[left].isalnum():
            left += 1

        while left < right and not s[right].isalnum():
            right -= 1

        if s[left].lower() != s[right].lower():
            return False

        left += 1
        right -= 1

    return True
```

## Complexity

Time:

```text
O(n)
```

Each character is visited at most once by either `left` or `right`.

Space:

```text
O(1)
```

No cleaned string is created. Only two pointers are used.

## Mistakes Caught

- Output is a boolean, not a transformed string.
- Two pointers does not improve Big-O time from `O(n)` to less than `O(n)`.
- The main benefit here is reducing extra space from `O(n)` to `O(1)`.
- Negative indexing for the right pointer makes crossing conditions harder to reason about.
- Use positive indices:

```text
left = 0
right = len(s) - 1
while left < right
```

- Inner loops also need `left < right` because they modify the pointers.
- Compare characters, not indices:

```python
s[left].lower() == s[right].lower()
```

## Pattern Summary

Two pointers from both ends:

```text
while left < right:
    move left until it points to a useful value
    move right until it points to a useful value
    compare
    move inward
```
