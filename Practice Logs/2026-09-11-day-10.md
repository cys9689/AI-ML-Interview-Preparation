## Problem 1: Minimum Window Substring

### Key Idea

Use a variable-size sliding window.

Maintain:

```text
need: required character counts from t
window: current window character counts
required: number of unique required characters
formed: number of required characters currently satisfied
```

Window is valid when:

```text
formed == required
```

When expanding right:

```text
if ch in need and window[ch] == need[ch]:
    formed += 1
```

When shrinking left:

```text
if left_ch in need and window[left_ch] < need[left_ch]:
    formed -= 1
```

### Final Code

```python
def minWindow(s, t):
    need = {}
    window = {}
    formed = 0
    left = 0
    min_len = float("inf")
    start = 0

    for ch in t:
        need[ch] = need.get(ch, 0) + 1

    required = len(need)

    for right in range(len(s)):
        ch = s[right]
        window[ch] = window.get(ch, 0) + 1

        if ch in need and window[ch] == need[ch]:
            formed += 1

        while formed == required:
            current_len = right - left + 1

            if current_len < min_len:
                min_len = current_len
                start = left

            left_ch = s[left]
            window[left_ch] -= 1

            if left_ch in need and window[left_ch] < need[left_ch]:
                formed -= 1

            left += 1

    if min_len == float("inf"):
        return ""

    return s[start:start + min_len]
```

### Complexity

Let:

```text
n = len(s)
m = len(t)
```

Time:

```text
O(n + m)
```

Space:

```text
O(k)
```

where `k` is the character set size.

## Problem 2: Valid Parentheses

### Key Idea

Use a stack because brackets follow LIFO order:

```text
last open bracket must be closed first
```

Rules:

```text
open bracket -> push
close bracket -> stack must not be empty, pop and match
end -> stack must be empty
```

### Final Code

```python
def isValid(s):
    stack = []
    close_to_open = {")": "(", "]": "[", "}": "{"}

    for ch in s:
        if ch in ["(", "[", "{"]:
            stack.append(ch)

        if ch in [")", "]", "}"]:
            if not stack:
                return False

            top = stack.pop()

            if close_to_open[ch] != top:
                return False

    return not stack
```

### Simplified Version

```python
def isValid(s):
    stack = []
    close_to_open = {
        ")": "(",
        "]": "[",
        "}": "{",
    }

    for ch in s:
        if ch in close_to_open:
            if not stack or stack.pop() != close_to_open[ch]:
                return False
        else:
            stack.append(ch)

    return not stack
```

### Complexity

Time:

```text
O(n)
```

Space:

```text
O(n)
```

Worst case:

```text
all characters are open brackets
```

## Mistakes Caught

- `required = len(need)`, not the total length of `t`.
- `formed` counts how many required character types are satisfied, not total matched characters.
- Increase `formed` only when `window[ch] == need[ch]`.
- Decrease `formed` only when removing a character makes `window[ch] < need[ch]`.
- In slicing, `min_len` is a length, not an end index:

```python
s[start:start + min_len]
```

- Python list uses `append`, not `push`.
- For Valid Parentheses, stack having leftovers means invalid.
