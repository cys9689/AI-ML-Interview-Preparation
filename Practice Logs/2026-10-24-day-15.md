## Key Ideas

Scan every cell. When an unvisited land cell is found, start BFS for its connected component. Explore only up, down, left, and right. Mark a coordinate visited when enqueuing it, so it enters the queue at most once.

Number of Islands increments the island count once per BFS start. Max Area of Island resets area for each BFS, increments it for every dequeued cell, and updates the maximum after that BFS ends.

## Final Implementations

```python
from collections import deque

def numIslands(grid):
    if not grid:
        return 0
    visited = set()
    islands = 0
    for r in range(len(grid)):
        for c in range(len(grid[0])):
            if grid[r][c] == "1" and (r, c) not in visited:
                islands += 1
                queue = deque([(r, c)])
                visited.add((r, c))
                while queue:
                    row, col = queue.popleft()
                    for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                        nr, nc = row + dr, col + dc
                        if 0 <= nr < len(grid) and 0 <= nc < len(grid[0]):
                            if grid[nr][nc] == "1" and (nr, nc) not in visited:
                                visited.add((nr, nc))
                                queue.append((nr, nc))
    return islands

def maxAreaOfIsland(grid):
    if not grid:
        return 0
    visited = set()
    max_area = 0
    for r in range(len(grid)):
        for c in range(len(grid[0])):
            if grid[r][c] == 1 and (r, c) not in visited:
                queue = deque([(r, c)])
                visited.add((r, c))
                area = 0
                while queue:
                    row, col = queue.popleft()
                    area += 1
                    for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                        nr, nc = row + dr, col + dc
                        if 0 <= nr < len(grid) and 0 <= nc < len(grid[0]):
                            if grid[nr][nc] == 1 and (nr, nc) not in visited:
                                visited.add((nr, nc))
                                queue.append((nr, nc))
                max_area = max(area, max_area)
    return max_area
```

## Complexity

Both implementations: O(R * C) time and auxiliary space. Each cell enters the queue at most once; visited can contain all cells. Area counters take O(1) space.

## Mistakes and Learning

- A visited boolean matrix is valid too; this implementation uses a set of coordinate tuples.
- Store coordinates, not the land value, to distinguish cells.
- Set uses add((r, c)); deque uses append((r, c)).
- deque([(r, c)]) contains one coordinate; deque((r, c)) or deque([r, c]) contains two integers.
- Boundary checks must precede indexing; use if for checking a neighbor, not while.
- Count islands when discovering unvisited land, not during exploration of its neighbors.
- Number of Islands uses string "1"; Max Area of Island uses integer 1.
- Update max_area inside the new-island conditional, after BFS, so area is defined.
